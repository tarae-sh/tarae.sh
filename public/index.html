$ cargo install --git https://github.com/tarae-sh/tarae tarae

Why tarae

Never waits
LSP, parsing, git and disk stay off the key path. A frame in under 16 ms. Features
Claude as a verb
select, space i, say it. Review the diff. Claude
Sandboxed by default
Claude's commands run confined: Seatbelt, or Landlock and seccomp. The network goes through tarae. Threat model
Sessions side by side
a checkout, a Claude and a terminal each. See where each Claude reads and writes, and what would conflict, as it happens; :weave shows a file as they all merge. Bring them back. Claude
Review like a pull request
hunk by hunk, or at the turn's end. A second Claude reviews too. Claude
The web as text
:web <url> reads a page as its markdown, a buffer like code: gd follows a link. Claude reads pages through the same gate as its commands. Web pages
Helix's keys
the same keymap and command names (coming from Helix).
Plugins in Rust
sandboxed WebAssembly. Kubernetes beside your manifests.

Install

git clone https://github.com/tarae-sh/tarae && cd tarae
cargo install --path .
tarae .

macOS or Linux (WSL on Windows), with rustup and a C compiler. Claude features need Claude Code logged in. space ? finds any command; :tutor teaches the keys.
